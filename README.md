# Gym Logger App (Increment 1)
Goal: make a working interface that runs locally for 1 person

## How to Run
1. Clone repository 

```git clone https://github.com/mchenrep/Gym-Logger-Web-App-CEN4090L.git```

2. Activate virtual environment

Windows: ```.\venv\Scripts\Activate.ps1```  
Mac: ```source venv/bin/activate```  

3. Install dependencies 

```pip install -r requirements.txt```

4. Run app

```python ./app.py```

5. Test your implementations locally. Branch for your specific role.
